# URL Shortener API

A small backend API for shortening URLs, built as a learning project to practice
programming fundamentals, Docker, CI/CD, and observability (logging, metrics,
dashboards).

## Status

Milestone 1: minimal server running, no shortening logic yet.

## Setup (Windows, PowerShell)

```
git clone https://github.com/mangelica06/first-project.git
cd first-project
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open http://127.0.0.1:8000 in a browser. You should see:

```
{"message": "URL Shortener API is running"}
```

Interactive API docs (auto-generated by FastAPI) are available at
http://127.0.0.1:8000/docs.
